# ytmdl
simple python script for download music from youtube. need - yt-dlp and bgutil-ytdlp-pot-provider. for download just clone it, give "x" rules ytmdl and move it in "~/.local/bin". 

yt-dlp
```
curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o ~/.local/bin/yt-dlp
chmod a+rx ~/.local/bin/yt-dlp 
```

bgutil-ytdlp-pot-provider
```
yay -S bgutil-ytdlp-pot-provider
```

ytmdl
```
git clone https://github.com/stadimi0410-arch/ytmdl.git
cd ytmdl
chmod +x ytmdl
mv ytmdl ~/.local/bin/
cd ~/
```
